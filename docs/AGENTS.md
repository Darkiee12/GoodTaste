# Documentation-specific agent rules

Applies under `docs/`. Follow root `AGENTS.md`.

- Update the one canonical page for a concern; link to it elsewhere rather than copying it.
- Distinguish `Accepted`, `Proposed`, `Unverified`, and `Implemented` status clearly.
- ADRs capture rationale and tradeoffs; runbooks specify verified commands and outcomes.
- Prefer concrete acceptance criteria and failure behavior over motivational prose.
- Verify relative Markdown links and reconcile index references for new/renamed files.
